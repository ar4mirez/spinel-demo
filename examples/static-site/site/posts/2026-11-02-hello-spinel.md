Spinel runs this generator from one binary. Run `spinel run bin/build` and the site lands in `tmp/public/`.

## What a post can use

1. *Emphasis* and **strong** text
2. `inline code` and [links](https://github.com/ar4mirez/spinel)
3. Fenced code blocks:

```ruby
puts "Hello from #{RUBY_ENGINE}"
```
